Open the group in WhatsApp → ⋮ → More → Export chat → Include media → you'll get a .zip; unzip it and drop the _chat.txt here. ("Without media" is smaller but can strip captions on some WhatsApp versions — since captions are how this reads screenshot posts, include media to be safe. The photos/videos themselves aren't used or uploaded anywhere.)

Post progress as one WhatsApp message per day, covering Cardio (walk/run/cycle/hike — any activity), Strength (weights/calisthenics), Mobility (yoga/pilates) and Sleep:

Sagar : Cardio : 7000 Steps | Strength : 45 min | Mobility : 30 min | Sleep : 7.5 Hours

Keep doing exactly what you already do — screenshot your fitness app — and just paste this line as the caption on the screenshot instead of sending it bare. The caption comes through in the export text, so it parses the same either way. Order, spacing, and units like "Steps"/"min"/"Hours" don't matter — the parser just looks for each word followed by a number, wherever it appears. A screenshot with no caption (or text that doesn't match) shows up under "Needs a nudge" below so you can see who to remind. Nothing is sent anywhere — the file is parsed in your browser and stored only in this browser (localStorage).
